# Archived MS-DOS source repository

This repository is a read-only historical archive. Its final active commit is
[`81e9684`](https://github.com/ddanila/MS-DOS/commit/81e9684efbeb694e0676b035d63415f20dca0555).

Active development, issues, builds, tests, releases, and the maintained source
now live in [`ddanila/msdos`](https://github.com/ddanila/msdos). The complete
source history was imported without squashing and the maintained tree is at
[`src/v4.0`](https://github.com/ddanila/msdos/tree/master/src/v4.0).

Branches, tags, releases, licenses, attribution, and old commit URLs are kept
here for provenance and recovery.
